# API Specification

## Overview
- **API style**: REST/JSON over HTTPS (D3), base URL `/api/v1`
- **Auth method**: JWT bearer (local auth, `Authorization: Bearer <token>`), policy-based authorization + data-scope enforcement (D3-6)
- **Docs**: OpenAPI (Swagger) generated by ASP.NET Core
- **Field convention**: camelCase JSON (IRPC standard); routes lowercase plural

## Conventions
- **Pagination** (offset, D3-7): `?page=1&pageSize=25` → response `{ items, page, pageSize, totalCount, totalPages }`
- **Filtering**: query params ต่อ field เช่น `?riskLevel=Critical&businessUnit=IT&status=Assigned&isKev=true&cve=CVE-2024-...&ageDaysMin=30&detectedFrom=&detectedTo=`
- **Sorting**: `?sort=riskScore:desc,detectedAt:asc`
- **Rate limit**: per-client (NFR-19) → `429` + `Retry-After` เมื่อเกิน (EX-110)
- **Versioning**: URI prefix `/api/v1`
- **Data scope**: ทุก list/detail endpoint กรองตาม scope ของผู้ใช้โดยอัตโนมัติ (FR-63)

## Error Format (RFC 7807 ProblemDetails)
```json
{
  "type": "https://svm/errors/invalid-transition",
  "title": "Invalid status transition",
  "status": 422,
  "detail": "ไม่สามารถเปลี่ยนจาก 'New' เป็น 'Closed' ได้",
  "code": "WORKFLOW_INVALID_TRANSITION",
  "requestId": "6f1c...",
  "errors": { "field": ["message"] }
}
```
Status usage: 400 (validation), 401 (unauthenticated), 403 (permission/scope), 404 (not found/scope-hidden), 409 (concurrency/conflict), 422 (business rule), 429 (rate limit), 500 (unexpected — no stack trace, NFR-40).
